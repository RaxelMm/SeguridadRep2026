# Descripcion
The one time pad can be cryptographically secure, but not when you know the key. Can you solve this? We've given you the encrypted flag, key, and a table to help `UFJKXQZQUNB` with the key of `SOLVECRYPTO`. Can you use this [table](https://challenge-files.cylabacademy.net/library/14a944b4b00c6d6e9213b62098e0c8a8d77219757b1a51d9af4bc15e263b6b92/table.txt) to solve it?.
## Solucion
1. Se tiene el texto cifrado: UFJKXQZQUNB
2. La clave es: SOLVECRYPTO
3. Se usa la tabla Vigenere proporcionada para descifrar.
4. Para descifrar, se busca en la fila de la clave y se localiza la letra cifrada en esa fila; la columna correspondiente da la letra original.
5. Descifrando letra por letra:
   U - S = C
   F - O = R
   J - L = Y
   K - V = P
   X - E = T
   Q - C = O
   Z - R = I
   Q - Y = S
   U - P = F
   N - T = U
   B - O = N
6. El mensaje descifrado es: CRYPTOISFUN
7. La flag, en mayusculas y con formato academy{}, es: academy{CRYPTOISFUN}
## Notas Adicionales
- **Categoria**: Cryptography -> Cifrado Vigenere.
- **Vigenere**: Cifrado polialfabetico que usa una palabra clave para desplazar cada letra del mensaje.
- La tabla proporcionada es la tabla de Vigenere estandar.
- El mensaje "CRYPTOISFUN" se lee como "CRYPTO IS FUN".
- Herramientas: CyberChef (Vigenere Decode), dCode, script Python.
- Flag: academy{CRYPTOISFUN}
