# Descripcion
What does asm1(0x3ac) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/3092741d30520956c5a7e9586f5e3bd44a0471b713081c233b72c5378029e5d1/test.S).
## Solución

El reto nos entrega un archivo de ensamblador x86 (`test.S`) y pide calcular qué valor retorna la función `asm1(0x3ac)` sin ejecutarla, razonando a mano la lógica de saltos condicionales.

**Traza de ejecución con `arg = 0x3ac` (940 decimal):**

1. `cmp [ebp+0x8], 0x33d` → compara 940 con 829

2. `jg <asm1+37>` → 940 > 829 → **salto tomado**

3. `cmp [ebp+0x8], 0x5f0` → compara 940 con 1520

4. `jne <asm1+54>` → 940 ≠ 1520 → **salto tomado**

5. `mov eax, [ebp+0x8]` → `eax = 0x3ac`

6. `add eax, 0x14` → `eax = 0x3ac + 0x14 = 0x3c0`

7. `ret` → devuelve `0x3c0`

Respuesta: `0x3c0`

## Notas Adicionales

- **Instrucción `jg`** (*Jump if Greater*): Salta si el resultado de la comparación anterior indica que el primer operando es **estrictamente mayor** que el segundo (comparación con signo). Equivale a la condición `>` en C.

- **Instrucción `jne`** (*Jump if Not Equal*): Salta si los operandos de la última `cmp` son **distintos**. Equivale a `!=` en C.

- **Convención de llamada x86 (cdecl)**: El primer argumento de una función se pasa en la pila en `[ebp+0x8]` (8 bytes por encima del EBP guardado, saltando los 4 bytes del EIP de retorno y los 4 bytes del EBP anterior). El valor de retorno se devuelve en el registro `eax`.

- **Resumen de la función** (pseudocódigo C):

  `c`

  `int asm1(int x) {`

      `if (x > 0x33d) {`

          `if (x == 0x5f0)`

              `return x - 0x14;`

          `else`

              `return x + 0x14;  // ← se ejecuta este caso`

      `} else {`

          `if (x == 0x225)`

              `return x + 0x14;`

          `else`

              `return x - 0x14;`

      `}`

  `}`
