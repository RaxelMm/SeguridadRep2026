# Descripcion
What is 0x3D (base 16) in decimal (base 10)?
## Solucion
```
Python 3.10.12 (main, Mar  3 2026, 11:56:32) [GCC 11.4.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> int(0x3D)
61
```
picoCTF{61}
## Notas Adicionales
+ La funcion int convierte cualquier numero a base 10 , el segundo parametro indica la base en la que esta el numero
