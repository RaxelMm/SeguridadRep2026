## Descripcion
Download this image and find the flag.
## Solucion
1. Descargar la imagen proporcionada (por ejemplo, `pico.flag.png`).
2. La pista indica que el mensaje termina en `$t3g0`, un delimitador comun en la codificacion LSB (Least Significant Bit).
3. Extraer los bits LSB de los canales RGB. Como no se cuenta con `zsteg`, se puede usar un script en Python con la libreria Pillow:
   python
   from PIL import Image
   import re
   img = Image.open('pico.flag.png')
   width, height = img.size
   pixels = img.load()
   bits = ""
   for y in range(height):
       for x in range(width):
           r, g, b = pixels[x, y][:3]
           bits += str(r & 1)
           bits += str(g & 1)
           bits += str(b & 1)
   mensaje = ""
   for i in range(0, len(bits), 8):
       byte = bits[i:i+8]
       if len(byte) == 8:
           mensaje += chr(int(byte, 2))
   match = re.search(r'academy\{.*?\}|picoCTF\{.*?\}', mensaje)
   if match:
       print("FLAG:", match.group(0))

4. El script extrae la flag oculta en los bits menos significativos y la imprime.
    
5. Ajustar el prefijo segun la plataforma (academy{} para CyLab).  
    La flag es: `academy{7h3r3_15_n0_5p00n_a9a181eb}` (verificar el sufijo exacto con el script).
    

## Notas Adicionales

- **Categoria**: Forensics -> Esteganografia en imagenes (LSB).
    
- **LSB (Least Significant Bit)**: Tecnica que oculta informacion modificando el bit menos significativo de cada pixel. Es imperceptible al ojo humano.
    
- **Herramientas alternativas**:
    
    - `zsteg` (Ruby, linea de comandos)
        
    - `Stegsolve` (Java, interfaz grafica)
        
    - `Aperi'Solve` (Online, [https://www.aperisolve.com/](https://www.aperisolve.com/))
        
    - Scripts en Python con `Pillow`
        
- La pista `$t3g0` es el delimitador que indica el final del mensaje oculto.
