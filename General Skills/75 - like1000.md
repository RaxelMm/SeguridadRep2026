# Descripcion
This [.tar file](https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar) got tarred a lot.
## Solucion
1. Descargar `1000.tar`.
2. Script de Python para extraer en bucle:
   - `tarfile.open(nombre, "r").extractall()` en un `for i in range(1000, 0, -1)`.
   - Cada iteración extrae `{i}.tar` y expone `{i-1}.tar`.
3. Al final aparece `flag.png`.
4. Abrir la imagen → flag.
## Notas Adicionales
- Concepto: TAR anidado (nested archives).
- La pista "Try and script this" es literal — hacerlo a mano tomaría horas.
- Python `tarfile` viene en la stdlib, no requiere instalación.
- Windows 10+ tiene `tar` nativo desde CMD/PowerShell.
- Flag: `picoCTF{l0t5_0f_TAR5}` (o similar según versión).
